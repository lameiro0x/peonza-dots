# Waybar slot samples (contract v1)

What agentd writes to `$XDG_RUNTIME_DIR/agentd/waybar/`, with `OUTPUT` replaced by the
Waybar output name (`$WAYBAR_OUTPUT_NAME`, e.g. `DP-1`, or `HEADLESS-1` on the stage).

- `OUTPUT-<n>.json` (n = 1..11): `{"text": pango, "tooltip": pango, "class": [...]}`.
  class ⊆ `empty | occupied | active | waiting | working | off`.
  text = key numeral · icon · project · (` · ` title, when width allows). Pango-escaped.
  Colours in the markup are the current theme's greys only (`fg0 fg1 fg2 busy ink_on_pill
  dim_on_pill` from `~/.config/ryce/palette.json`, the link to the current `theme.json`);
  the **waiting** state is drawn by waybar/style.css as a ring in the theme's `signal`
  (the markup never carries it). After a theme switch, SIGHUP to agentd
  (`systemctl --user reload agentd`) rewrites every file in the new theme's greys.
- `OUTPUT-window.json`: the focused window line. For a Claude window:
  `project › first doing line` (the title already lives in the workspace slot and its
  tooltip; measured by slice B: at 1920 px with 4 occupied slots the left island fits
  ~42 chars, and `project — title › doing` cut the useful part). Tooltip: `project — title`
  plus every doing line. class ⊆ `window | claude | empty`.
- `agents.json`: `{"text": "<icon> N", "tooltip": "...", "class": ["waiting"|"busy"|"calm"]}`
  N = waiting count, or busy count when nobody waits. Click toggles the Quickshell sidebar.

Contrast: `fg2` is a mark colour (key numeral, icons, empty-slot numerals), never words;
words use `fg0`/`fg1`. waybar/tests/test_contrast.py checks every theme.

These files are agentd's real output for `agentd/tests/fixtures/stage` in Origen, the
built-in default (regenerate them with `PYTHONPATH=agentd python3 -m agentd --once
--no-dispatch --fixtures agentd/tests/fixtures/stage --outdir DIR --palette DIR/none.json`
and rename `HEADLESS-1-*` to `OUTPUT-*`).
Slots 1..`always_shown` (5) always exist; 6..11 only when occupied or active (else `off`).
Generated by a script with `chr()` — never type Nerd Font PUA glyphs by hand (playbook trap).
